# Project scope

## Objective

Create a disciplined engineering and research workflow for centrifugal pump analysis grounded in geometry, operating conditions, and external solver integration.

## Scope of this repository

This repository currently covers the foundational layer of the workflow:
- parameter definition,
- basic geometric generation,
- validation checks,
- output generation for downstream CFD tools.

## Non-goals for this phase

The following are excluded from the current baseline claim:
- a verified commercial-equivalent CFD solver,
- fully validated 3D fluid modeling,
- transient rotor-stator simulation,
- cavitation prediction with uncertainty bounds,
- final engineering acceptance.

## Research direction

The project roadmap is:
- parametric baseline geometry,
- 3D fluid volume extraction,
- mesh quality assessment,
- steady RANS solution,
- transient flow analysis,
- cavitation and NPSH validation,
- publication-quality benchmark comparison.

## Positioning statement

The present repository should be understood as a research and pre-processing foundation, not as a final CFD result package.
