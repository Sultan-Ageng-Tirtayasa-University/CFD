# Academic frontend design

The frontend has been restyled as an engineering/research dashboard rather than a commercial product landing page.

Design decisions:
- restrained navy, blue, grey, and evidence-status colors;
- serif hierarchy for scientific section titles;
- compact tables and explicit units;
- visible distinction between OEM data, assumptions, CFD rules, and missing data;
- reduced decorative gradients and rounded-card emphasis;
- responsive layout retained for laboratory and teaching use.

The visual redesign does not change solver capability or validation status. LBM remains a qualitative 2D visualization and the C++ RANS/OpenFOAM output remains a scaffold until a real volume mesh and solver execution are supplied.
